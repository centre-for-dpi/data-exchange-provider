# K0 + K1 — Base del repositorio y modo `canal`: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un binario y una imagen `rid-node` que, en modo `canal`, se enrolan en el portal real, levantan el túnel, sirven solo al gateway y reenvían a la API propia de la entidad, probado de punta a punta.

**Architecture:** un binario Go con paquetes por responsabilidad:
- `config`, `state`, `contract`, `tunnel`, `server`, `proxy` y `agent`;
- `cmd/rid-node` los conecta.

El plano de datos (túnel, TLS y proxy) no depende del plano de control: si el portal no responde, el nodo sigue sirviendo. Se reutiliza lo aprendido en `spikes/go-node/`, pero el código es nuevo y probado.

**Tech Stack:**
- Go 1.27, `log/slog` y `flag` (sin frameworks de CLI);
- `golang.zx2c4.com/wireguard` (MIT) con `tun/netstack` (gVisor, Apache-2.0);
- `gopkg.in/yaml.v3`;
- `github.com/santhosh-tekuri/jsonschema/v6` (Apache-2.0), solo en pruebas;
- Docker, con imagen final `scratch`.

**Spec:** `docs/ARCHITECTURE.md`, `docs/BACKLOG.md` (K0 y K1), `docs/adr/0001-*.md` y `docs/adr/0002-*.md`. El contrato es `../data-exchange/docs/contracts/node-contract-v1.openapi.json`.

## Global Constraints

- **Módulo:** `github.com/centre-for-dpi/data-exchange-provider`, con `go 1.27` en `go.mod`.
- **Idioma:**
  - código, identificadores, commits y comentarios en inglés;
  - mensajes a la entidad (problem+json `title`, mensajes de la CLI y de `doctor`) en español.
- **Licencias:** solo OSI de la lista de `CLAUDE.md`. Nada se agrega sin pasar `make licenses`.
- **Logs:**
  - **nunca** cuerpos, ruta real, query ni valores de cabeceras;
  - la ruta se registra como plantilla;
  - los secretos nunca van a un log, ni siquiera en debug.
- **Secretos** solo en archivos (`/run/secrets/...`), nunca en variables de entorno ni en `node.yaml`.
- **Estado:** `/var/lib/rid-node/state.json`, 0600, con escritura atómica.
- **Contrato v1:**
  - `kitVersion` con el patrón `^\d+\.\d+\.\d+(?:[-+][0-9A-Za-z.-]+)?$`;
  - nombre de servicio con `^[a-z0-9][a-z0-9-]*$` (máximo 80);
  - ruta con `^\/[A-Za-z0-9._~\-/]*$` (máximo 200);
  - `servicePort` 8443;
  - CSR con `CN=rid-node` y sin SAN.
- **TLS del nodo:** TLS 1.3, `RequireAndVerifyClientCert` con la raíz de la red, CN exacto = `gatewayClientName` y SNI = `nodeName` en `VerifyConnection`. Si `Host` no es `nodeName`, 421.
- **Imagen:** `scratch`, usuario `65532:65532`, `ENTRYPOINT ["/rid-node","run"]` y certificados raíz en `/etc/ssl/certs/ca-certificates.crt`.
- **Variantes:**
  - por defecto `completo`;
  - `-tags canal` da la variante `canal`;
  - en `canal`, un servicio `type: instant` es un error de configuración;
  - en `completo`, `instant` da "no disponible todavía (K3)" hasta K3.

## Review Focus

1. **`state.json` corrupto o ilegible.** El nodo no debe enrolarse de nuevo en silencio: termina con un mensaje que menciona `install.sh reenrolar`. Lo prueba la Task 5.
2. **Falta el token o está vacío en el primer arranque.** El nodo no entra en un ciclo de caídas: registra en español "esperando el token…" y vuelve a mirar cada 10 s. Lo prueba la Task 10.
3. **El portal o el gateway no responden durante horas.** El túnel y el servidor siguen atendiendo al gateway, y el heartbeat reintenta con backoff hasta 60 s. Lo prueba la Task 11.
4. **El API interna está caída o es lenta.** El proxy responde rápido con 502 o 504 en problem+json, sin colgarse, y la salud del heartbeat pasa a `degraded`. Lo prueban las Tasks 9 y 11.
5. **El reloj del servidor está desfasado.** `doctor` lo detecta comparando con la cabecera `Date` del portal y lo explica (más de 60 s es error). Lo prueba la Task 12.

**Interfaces:**
- Consumes: `contract.Control`, `state.Store`, `proxy.Probe` y `tunnel.Tunnel.LastHandshake`.
- Produces:
  ```go
  type ServiceRuntime struct { Info contract.ServiceInfo; Probe func(context.Context) error }
  type Status struct {
      NodeID, NodeName, PortalState string // last status from heartbeat, or "unreachable" / "rejected"
      LastHeartbeat, LastHandshake, CertificateNotAfter time.Time
      Health contract.Health; Services []ServiceStatus; Notices []string; KitVersion, Variant string
  }
  type Controller struct { /* injectable: Now, intervals */ }
  func NewController(st *state.State, store state.Store, ctl *contract.Control, cert *atomic.Pointer[tls.Certificate],
      services []ServiceRuntime, tun interface{ LastHandshake() time.Time }, kitVersion string, log *slog.Logger) *Controller

  func compareSemver(a, b string) int
  ```
  Reglas:
  - **Intervalo:** `nextHeartbeatSeconds` de la última respuesta, o `HeartbeatIntervalSeconds`, con ±10 % de *jitter*. Ante un error, backoff exponencial de 5 s a 60 s.
